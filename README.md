🎬 Proyecto Películas Next.js

Este proyecto es una plataforma de visualización de películas desarrollada con Next.js, Swiper y Tailwind CSS. La aplicación ofrece una experiencia dinámica e interactiva para descubrir, buscar y guardar películas favoritas en una interfaz moderna y fácil de usar.

Características:

    Exploración de películas: Los usuarios pueden navegar entre diversas películas, con carátulas destacadas y una interfaz fluida implementada con Swiper.
    Visualización de detalles: Cada película incluye una descripción, fecha de lanzamiento, puntuación de la audiencia y la opción de agregar a favoritos.
    Funcionalidad de búsqueda: Los usuarios pueden buscar películas mediante palabras clave o filtrar por género.
    Sistema de favoritos: Los usuarios tienen la posibilidad de guardar sus películas favoritas para acceder a ellas fácilmente en cualquier momento.
    Interfaz optimizada: La aplicación está diseñada con Tailwind CSS para ofrecer una experiencia visual limpia y responsiva, optimizada tanto para dispositivos móviles como para escritorio.

🚀 Comenzando

Sigue estos pasos para levantar el servidor de desarrollo en tu máquina local:

bash

npm run dev
yarn dev
pnpm dev
bun dev

Abre http://localhost:3000 en tu navegador para ver el resultado.
📁 Estructura del Proyecto

El proyecto está basado en el archivo app/page.tsx, el cual se puede modificar para actualizar la página principal. Las actualizaciones se reflejan de manera automática.
🎨 Tecnologías Utilizadas

    Next.js: Framework para aplicaciones web basadas en React.
    Swiper: Para carruseles de contenido deslizante.
    Tailwind CSS: Framework de CSS para un diseño eficiente y flexible.
    Inter: Tipografía optimizada cargada de manera automática.
